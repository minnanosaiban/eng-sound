# English Sound Selector

英文を貼り付け、選んだ単語・フレーズを音声リストに追加し、間を空けて聞き比べるWebアプリです。

> 選ぶ → 追加する → 間を空けて聞き比べる

仕様は `sound_selector.md`（開発指示書 v3）、作業ルールは `CLAUDE.md` を参照してください。

## 起動・ビルド・テスト

```bash
npm install
npm run dev        # 開発サーバー
npm run typecheck  # 型チェック
npm run test       # テスト（Vitest / jsdom）
npm run build      # 本番ビルド（dist/）
```

## 基本操作

1. 英文または単語リストを貼り付けます（貼り付けると自動で「選択」モードになります）。
2. 聞きたい範囲を選びます。`現在の選択` に表示され、ボタンを押しても保持されます（`✕` で解除）。
3. `選択部分を再生` で確認し、`音声リストに追加` でリストへ保存します。離れた箇所も同じ操作で追加できます。
4. `リストを再生` で、各項目を **独立した発話** として、設定した休止を挟みながら順に読み上げます。複数項目を連結して1回の読み上げにすることはありません。
5. `停止` は発話中・休止中のどちらでも有効です。

### 編集モードと選択モード

- **編集**：英文の貼り付け・修正ができます。
- **選択**：入力欄が読み取り専用になり、スマートフォンでもキーボードを出さずに範囲選択できます。

### 設定

- 読み上げ速度：0.5x / 0.75x / 1.0x
- 読み上げ間隔：0.5〜2.0秒（`onend` の後に待機します）
- リピート：1 / 3 / 5回（**リスト全体の再生のみ**。選択部分・個別項目・全文は常に1回）

リスト再生中は上下移動・個別削除・すべて削除が無効になります（追加は可能で、次回の再生から対象になります）。

## 使用技術と注意

- 読み上げには Web Speech API を使用します。外部API・APIキーは使いません。
- OS やブラウザにより、使われる音声や聞こえ方が異なります。
- ブラウザの音声によっては、読み上げる英文がブラウザ提供元のサーバーで処理される場合があります（アプリ自身が英文を外部へ送信することはありません）。
- 0.5x は、通常速度の録音を単純に遅くした音ではありません。TTSエンジンが低速用に読み直すため、実際の会話音声を忠実に引き延ばしたものではありません。
- 英文と音声リスト、設定は `sessionStorage` に一時保存されます。**タブを閉じると消えます**（現在の選択・再生状態は保存しません）。

## GitHub Pages への公開手順

Vite の `base` は `./` なので、ビルド結果をそのまま静的ホスティングできます。

1. このフォルダを GitHub リポジトリとして push します。
2. `npm run build` で `dist/` を生成します。
3. `dist/` の内容を `gh-pages` ブランチへ公開するか、GitHub Actions（`actions/upload-pages-artifact` と `actions/deploy-pages`）で `dist/` をデプロイします。
4. リポジトリの Settings → Pages で公開元を設定します。

## 既知の制約

- 長い範囲（目安として1文を大きく超える範囲）を選択すると、Chrome では途中で止まる場合があります。選択範囲は分割しないため、上限時間を過ぎると `読み上げが途中で止まった可能性があります` と表示します。その場合は範囲を短くするか、全文再生を使ってください。
- 画面が非表示になる（別アプリへ切り替える）と再生は停止し、戻っても自動再開しません。
- 実機（iOS Safari / Android Chrome）での手動受け入れテストは未実施です。

## 実装上の判断

- 選択モードの実装方式：第一候補の `readOnly` を採用（iOS Safari で範囲選択ができない場合は `inputMode="none"` へ切り替える。手動テスト7で要確認）。
- 全文再生で上限時間に達した場合は、通知を表示して次の文へ進む。
- 個別項目の再生中も、その項目を再生中表示（強調）にする。
- 停止・再生開始の待機（50ms）中も `playbackKind` を設定し、ボタンの状態を即座に切り替える。
- 空白だけの範囲を選択した場合は、保持中の選択を変更しない。
- 保存済みセッションがない起動時は、初期サンプルを表示して選択モードで始める。
- `停止` ボタンは再生していないときは無効にする。`aria-live` は再生状態表示とエラー／通知にのみ付ける。
- 絵文字アイコンのボタンには `aria-label` を付けている。
